# Day 07 – Lists

This repository contains practice programs focused on **Python Lists**, starting from basic operations to real-world problem solving.

---

## Topics Covered

- List creation and indexing
- List traversal using loops
- Conditional logic with lists
- Built-in list methods
- Nested lists
- Real-world list-based problems

---

## File Description

### basic_list_operations.py
- Creating lists
- Indexing and slicing
- Adding and removing elements
- Length of list
- Sum, max, min operations

---

### list_traversal_conditions.py
- Traversing lists using `for` loop
- Applying `if-else` conditions
- Counting elements based on conditions
- Filtering data from lists

---

### list_methods_practice.py

- `reverse()`
- `count()`
- `index()`
- `extend()`

### nested_list_problems.py
- Accessing nested lists
