# Day 01 – Python Operators

This folder contains a complete and structured implementation of **all Python operators**.
Each program demonstrates a specific operator category using **real-world inspired examples**
and includes the **expected output in comments** for quick review.



##  Operators Covered

- Arithmetic Operators (`+`, `-`, `*`, `/`, `//`, `%`, `**`)
- Relational / Comparison Operators (`==`, `!=`, `>`, `<`, `>=`, `<=`)
- Logical Operators (`and`, `or`, `not`)
- Assignment Operators (`=`, `+=`, `-=`, `*=`, `/=`, `//=`, `%=`, `**=`)
- Bitwise Operators (`&`, `|`, `^`, `~`, `<<`, `>>`)
- Membership Operators (`in`, `not in`)
- Identity Operators (`is`, `is not`)
- Unary Operators (`+`, `-`, `not`, `~`)
- Ternary (Conditional) Operator
- Operator Precedence & Associativity
