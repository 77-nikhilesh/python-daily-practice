# Day 03 – Loops in Python 

This folder contains **comprehensive practice programs on Python loops**, focusing on building strong logic and iteration skills.  
Each file includes **multiple problems**, well-structured code, and **expected outputs mentioned in comments** for clarity.

---

## Files Overview

- **for_loop_basics.py**
  - Printing sequences
  - Even numbers
  - Squares of numbers

- **while_loop_basics.py**
  - Reverse counting
  - Sum of natural numbers
  - Number reversal

- **range_function.py**
  - range() with different arguments
  - Forward and reverse iteration

- **break_continue_pass.py**
  - Loop control statements
  - break, continue, and pass examples

- **nested_loops.py**
  - Multiplication tables
  - Coordinate pair generation

- **pattern_printing.py**
  - Star patterns
  - Reverse patterns

- **loop_with_else.py**
  - for-else behavior
  - Loop completion vs break

- **problems_real_world.py**
  - Digit counting
  - Prime number check
  - Factorial calculation
