# Day 04 – Functions in Python

This folder contains **comprehensive practice programs on Python functions**, covering multiple concepts and real-world examples.  

---

## Files Overview

- **basic_functions.py**
  - Simple greetings
  - Separator lines
  - Print squares
  - Pass statement examples

- **functions_with_arguments.py**
  - Addition and multiplication
  - Area calculation
  - Celsius to Fahrenheit
  - Multiple greetings

- **return_values.py**
  - Square and cube calculations
  - Even/odd checks
  - Maximum of two numbers
  - Factorial calculation

- **default_and_keyword_args.py**
  - Default arguments
  - Keyword arguments
  - Sum and multiplication with defaults
  - Greeting with default values

- **variable_length_args.py**
  - *args addition and multiplication
  - **kwargs user info
  - Maximum number with *args
  - Default values using **kwargs

- **lambda_functions.py**
  - Square, cube, addition
  - Even/odd check
  - Maximum of two numbers

- **recursion_examples.py**
  - Factorial
  - Fibonacci
  - Sum of numbers
  - Reverse string
  - Count digits
